Odin Wire Protocol Reverse Engineered Specification

Wire-level state machine reconstructed from Samsung LOKE Little Kernel (LK) decompilation

01 Init

Handshake & Ping

Host sends ASCII string "ODIN" (4 bytes). Bootloader verifies cable and echoes "LOKE".

02 Opcode 0x64

Session Setup

Negotiates protocol tier: Odin v3 (1MB sequence buffer) or Odin v4 (8MB sequence). Hardware NAND erase (subcmd 0x07).

03 Opcode 0x66

Sequence Streaming

Transmits 512-byte aligned macro buffers. On final sequence block, bootloader validates SHA-256 and OEM RSA public keys.

04 Opcode 0x67

Session Commit

Clears emergency softbrick flag in secure param storage (0x01 -> 0x00) and executes device reset to One UI.

Protocol Frame Structure Specification

Offset Field Size Description
0x00 - 0x03 cmd_id 4 Bytes (u32 LE) Primary opcode: 0x64 (Setup), 0x65 (PIT), 0x66 (Flash), 0x67 (End)
0x04 - 0x07 subcmd_id 4 Bytes (u32 LE) Subcommand: 0x00 (Start sequence), 0x02 (Commit sequence), 0x07 (NAND wipe)
0x08 - 0x0B arg1 4 Bytes (u32 LE) Payload length or sequence byte count (aligned to 512-byte sector)
0x0C - 0x0F arg2 4 Bytes (u32 LE) Target partition ID from PIT table (e.g. 18 for BOOT, 30 for SUPER)
0x10 - 0x13 arg3 4 Bytes (u32 LE) Final block flag: 1 = verify signature & commit; 0 = stream next chunk
0x14 - 0x3FF zero_pad 1004 Bytes Zero-filled padding to fulfill strict 1024-byte control packet size

Flash Safety Protocol & Invariant Protections

Transport-level verification preventing permanent radio hardware bricking or IMEI loss

NVRAM & Baseband Write Invariant

Strict Compile-Time Enforcement

The cellular modem subsystem on Samsung Shannon SoCs relies on cryptographic NVRAM calibration partitions. Overwriting or wiping these blocks destroys factory radio coefficients, resulting in permanent baseband crashloops and irreversible IMEI loss.

  • EFS & SEC_EFS: Protected by hard refusal in flasher.rs
  • CPEFS: Cellular Processor baseband cache write-locked
  • KEYSTORAGE & KEYREFUGE: Hardware Knox keystore protected

PIT Boundary Pre-Flight Verification

Runtime Sector Mathematics

Before a single USB sequence packet is transmitted across the wire, exynos-loke-rescue cross-references the raw image payload size against the exact allocated block count in the target device's live partition table.

  • Payload Size ≤ PIT.block_count × 512 bytes enforced
  • Zero dynamic unsparse buffer overflows
  • Deterministic Little Kernel (LK) ACK validation
